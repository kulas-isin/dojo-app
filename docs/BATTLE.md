# ⚔️ PawDojo 對戰系統設計（復古寶可夢式）

決策：**PvE 回合制打道館主（AI 衛冕者）** · 數值 **種族基底 + id 雜湊** · 屬性 **寵物主題×元素** · **隨勝場升級** · 與**投票雙軌並存**。

---

## 1. 屬性系統（寵物主題 × 元素本質）
5 種屬性，走一個乾淨的五角克制環（每種剋 1、被剋 1、其餘中性）：

| 屬性 | 元素本質 | 剋制 → | 被剋 ← |
|---|---|---|---|
| 🔥 活力 Vigor | 火 | 🌿 自然 | 💧 溫柔 |
| 🌿 自然 Wild | 草 | ⚡ 敏捷 | 🔥 活力 |
| ⚡ 敏捷 Swift | 電 | 💧 溫柔 | 🌿 自然 |
| 💧 溫柔 Gentle | 水 | 🪨 憨厚 | ⚡ 敏捷 |
| 🪨 憨厚 Sturdy | 地 | 🔥 活力 | 💧 溫柔 |

- 克制：**×1.5**、被克：**×0.75**、其餘：**×1.0**。
- 好記：活力(火)燒自然(草)、自然(草)纏敏捷(電導體?其實用主題邏輯)…以主題為主、元素為輔味道。

## 2. 種族基底數值（Lv.1）
四項數值：**HP / 攻擊 ATK / 防禦 DEF / 速度 SPD**。

| 種族 | HP | ATK | DEF | SPD | 屬性傾向 |
|---|---|---|---|---|---|
| 🐱 貓 | 45 | 50 | 45 | 60 | 偏 ⚡敏捷 |
| 🐶 狗 | 60 | 60 | 45 | 35 | 偏 🔥活力 |
| 🐾 其他 | 50 | 50 | 50 | 50 | 偏 🌿自然 |

## 3. id 雜湊產生個體差異（IV）
用寵物 `id` 做**穩定雜湊**（同一隻永遠一樣）：
- 每項數值 +0～15 的個體值（IV）。
- 屬性：以種族傾向為**加權**，雜湊決定最終屬性（例如貓 60% 敏捷、其餘平分）。
- 一隻寵物的「數值卡」= 種族基底 + IV，並綁定 1 個屬性。

> 純函式 `deriveStats(pet)`：輸入 id/petType → 輸出 {type, hp, atk, def, spd, moves}。前端算即可，不必存 DB（存 `level` 就好）。

## 4. 成長（隨勝場升級）
- 寵物存 `level`（預設 1）；**PvE 打贏道館主 → level +1**。
- 每級各項數值 **×1.08**（約 +8%）。Lv.10 大約 2 倍。
- 顯示：檔案頁與對戰畫面顯示等級與數值卡。

## 5. 招式（依屬性自動給 3 招）
每隻 3 招，從其屬性的招式池抽（由 id 雜湊決定）：
- **本屬性攻擊**（威力 60，吃屬性克制）
- **強力一擊**（威力 85、命中略低 85%）
- **實用招**（威力 40 + 小效果，如降敵速/回自身少量 HP）

招式資料：`{ name, type, power, accuracy, effect? }`，做一張靜態表。

## 6. 傷害公式（簡化寶可夢）
```
base = ((2*Lv/5 + 2) * Power * ATK / DEF) / 50 + 2
damage = floor( base * typeMult * rand(0.85~1.0) )
```
- `typeMult` = 1.5 / 1.0 / 0.75（克制）。
- 命中判定：`rand() < accuracy`，未命中 = 0 傷害。

## 7. 回合制流程（PvE）
1. 進道館 → 若已有衛冕者 → 點「**對戰挑戰**」→ 進**對戰畫面**。
2. 雙方各出一隻（你選你的寵物、對手＝現任衛冕者，AI 操作）。
3. 每回合：你**選一招**；AI 依簡單策略選招（隨機/擇高傷）。依 **SPD** 決定先後，結算傷害。
4. 一方 HP 歸零 → 分勝負。
5. **你贏 → 成為新衛冕者**（更新道館 champion），**你的寵物 level +1**、記勝場、頒頭銜。
6. 輸了可再挑戰（可加冷卻，MVP 先不加）。

**AI 策略（MVP）**：70% 選當前對你**克制/高傷**的招，30% 隨機，讓它不無腦也不無敵。

## 8. 與投票雙軌並存
- **道館歸屬（實力）**：由 **PvE 對戰** 決定衛冕者。
- **人氣（popularity）**：**投票/讚**保留，做「**人氣排行榜**」與「本週人氣王」等榮譽，不影響道館歸屬。
- UI：道館頁同時有「⚔️ 對戰挑戰」與「❤️ 投人氣」兩顆；排行榜分「道館主」與「人氣王」兩個分頁。

## 9. 對戰畫面 UI（復古感）
- 上：對手寵物（頭像/插畫 + HP 條 + 屬性 + Lv）。
- 下：我方寵物（同上）。
- 底部：**招式選單**（4 格），顯示招式屬性與威力。
- 中央：出招動畫/傷害數字、"效果絕佳!" / "效果不佳…" 提示（吃克制時）。
- 走插畫風 + 我們的暖色 tokens。

## 10. 技術與資料
- 純前端可算的：`deriveStats(pet)`、傷害公式、AI、回合流程（不需即時後端）。
- DB 只需加：`pets.level int default 1`；結算時更新 champion（既有）＋ `pets.level+1`。
- 對戰過程是本機互動；**結果**（換衛冕者、升級）寫回雲端。
- 之後要 PvP 再擴充；MVP 先 PvE。
