# 🐾 PawDojo 頁面規格書（User Stories & Spec）

> 對應路線圖 `docs/ROADMAP.md`。每頁標註狀態：**[已實作]** 目前可用 · **[規劃中]** 下一階段 · **[未來]** 需後端。
> 權限相關以「統一寵物檔案模型」為準（見 ROADMAP 權限矩陣）。

## 角色定義
- **訪客**：未登入，只能瀏覽（未來上線帳號後）。
- **一般用戶**：登入者，可建道館、上傳挑戰、投票、建立自己的寵物、記錄浪浪。
- **飼主（owner）**：某個 `owned` 寵物檔案的擁有者。
- **回報者 / 照顧者（reporter / caretaker）**：某個 `stray` 浪浪檔案的管理者群。
- **管理員（admin）**：平台端，處理檢舉與濫用（未來）。

> ⚠️ 現階段為本機原型，只有一個模擬用戶（`me`）；權限以 `can*()` helper 判斷，
> 真正多人生效需 Phase 2 帳號＋後端。

## 1. 地圖 Map ‧ `app/(tabs)/index.tsx` [已實作]

**User Stories**
- 身為用戶，我想在地圖上看到附近的道館，以便就近挑戰。
- 身為用戶，我想在某個地點建立道館，讓這裡成為毛孩戰場。
- 身為關心浪浪的人，我想把流浪動物聚集地標記出來，讓大家區別。

**Spec**
- 進入點：App 啟動預設頁 / 分頁列。
- 元件：全螢幕地圖（原生 `react-native-maps`；Web 為示意地圖 fallback）、頂部標題列、右下「建立道館」FAB。
- 資料：所有 `gyms`、使用者定位（`expo-location`，失敗則用示範中心點）。
- 圖釘：一般道館＝珊瑚色；流浪聚集地＝沙綠色（依 `gym.isStray`）。
- 操作：點圖釘→道館頁；點空白/FAB→建立道館（帶入座標）。
- 狀態：無定位權限→用示範中心；離線地圖→Web fallback。
- 權限：任何登入者可建道館。

## 2. 建立道館 Create Gym ‧ `app/gym/create.tsx` [已實作]

**User Stories**
- 身為用戶，我想替一個地點命名、選圖示、寫介紹，建立專屬道館。
- 身為用戶，我想標記這是流浪動物聚集地，讓它在地圖上有區別。

**Spec**
- 進入點：地圖 FAB / 點地圖空白處（modal）。
- 欄位：名稱（必填, ≤20）、介紹（≤80）、圖示（Lucide 10 選 1）、`流浪動物聚集地` 開關、座標（唯讀，來自地圖）。
- 操作：「建立道館」→ 寫入 store → 導向新道館頁。
- 驗證：名稱空白時按鈕停用。
- 權限：任何登入者。

## 3. 道館頁 Gym Detail ‧ `app/gym/[id].tsx` [已實作]

**User Stories**
- 身為用戶，我想看到這座道館現任衛冕者是誰。
- 身為用戶，我想上傳我家毛孩來挑戰衛冕者。
- 身為觀眾，我想替喜歡的一方投票。
- 身為用戶，我想看到館內所有參賽者的排名。

**Spec**
- 進入點：地圖圖釘、排行榜列、建立道館後。
- 區塊：道館標頭（圖示/名稱/流浪徽章/介紹）、現任衛冕者卡、進行中對戰（雙方投票卡＋票數％＋倒數）、「發起挑戰」按鈕、道館排行清單。
- 資料：`gym`、`champion`、`activeBattle`、`entries`（依票數排序）。
- 操作：投票（每場一票）、結算對戰（示範用可提前）、發起挑戰→挑戰頁。
- 狀態：無衛冕者→提示第一個上傳者登頂；無對戰→只顯示衛冕者與排行。
- 權限：投票每人每場一次；上傳任何登入者。

## 4. 發起挑戰 Challenge ‧ `app/gym/challenge.tsx` [已實作]

**User Stories**
- 身為用戶，我想上傳毛孩的照片或影片、填名字與種類，向衛冕者下戰帖。

**Spec**
- 進入點：道館頁「發起挑戰」（modal）。
- 欄位：媒體（相簿選圖/影片，或範例素材）、毛孩名字（≤16）、種類（貓/狗/其他）。
- 邏輯：道館無衛冕者→直接登頂；有→建立一場對戰（挑戰者 vs 衛冕者）。
- 操作：「送出挑戰」→ 回道館頁看對戰。
- 驗證：需選媒體且填名字。

## 5. 探索 Discover Feed ‧ `app/(tabs)/discover.tsx` [規劃中]

**User Stories**
- 身為用戶，我想像滑 IG 一樣滑到別人的寵物與浪浪貼文，發現可愛的毛孩。
- 身為用戶，我想切換只看「浪浪」、「追蹤中」或「附近」的內容。
- 身為用戶，我想對貼文按讚、點進該寵物的檔案。

**Spec**
- 進入點：分頁列「探索」。
- 版面：頂部篩選 chip（`全部 / 浪浪 / 追蹤中 /（未來）附近`）＋貼文動態（大圖卡：頭像＋名字＋狀態、媒體、日記文字、讚數、時間）。
- 資料：所有 `visibility=public` 的 `posts`，關聯其 `pet`；依篩選與時間排序。
- 操作：按讚（`likePost`）、點頭像/卡片→寵物檔案、下拉更新。
- 狀態：空清單→引導建立第一隻寵物；篩選無結果→提示換條件。
- 權限：瀏覽/按讚任何登入者；只顯示 public 內容。

## 6. 寵物檔案 Pet Profile ‧ `app/pet/[id].tsx`（由現 `stray/[id]` 通用化）[規劃中]

> 同一頁服務 `owned`（個人寵物）與 `stray`（浪浪），依 `kind` 顯示不同資訊與權限。

**User Stories**
- 身為訪客，我想看到這隻寵物的照片牆與生活日記。
- 身為飼主，我想編輯我寵物的檔案、發新紀錄、設定公開或私人。
- 身為關心浪浪的人，我想幫這隻浪浪補充照片紀錄（共筆）。
- 身為照顧者，我想更新浪浪的狀態（待認養→已認養）或移除不當紀錄。
- 身為用戶，我想追蹤這隻寵物，之後在「追蹤中」看到牠的更新。

**Spec**
- 進入點：探索卡、浪浪列表、地圖流浪道館、我的寵物列表。
- 標頭：大頭貼、名字、種類、（stray）狀態徽章＋出沒地點、簡介、紀錄數/關注數、追蹤鈕。
- owned 專屬：`公開/私人` 狀態；飼主看到「編輯檔案」。
- stray 專屬：照顧者看到「編輯檔案 / 管理照顧者」；一般人看到「新增紀錄（共筆）」。
- 照片牆：3 欄 grid，點圖→大圖檢視。
- 每則紀錄操作：讚、（作者或照顧者/飼主）刪除、（任何人）檢舉。
- 權限（見矩陣）：
  - 改檔案：owned=owner；stray=reporter+caretakers。
  - 新增紀錄：owned=owner；stray=任何登入者。
  - 刪紀錄：作者本人，或 owner/caretaker。
- 狀態：無紀錄→引導新增；私人且非本人→顯示「此檔案為私人」。

## 8. 建立寵物檔案 Create Pet ‧ `app/pet/create.tsx`（現 `stray/create.tsx`）[已實作→通用化]

**User Stories**
- 身為飼主，我想建立我家寵物的檔案（可設公開/私人）。
- 身為用戶，我想替一隻浪浪建立檔案並成為第一位照顧者。

**Spec**
- 進入點：`我的`→我的寵物→新增（kind=owned）；探索/浪浪/地圖→建立浪浪（kind=stray）。
- 共同欄位：照片、暱稱（≤16）、種類。
- owned：`公開/私人` 開關（預設公開）；建立後 `ownerId=me`。
- stray：出沒地點、狀態（待認養/已結紮/已認養/未結紮）、簡介；建立後 `reporterId=me`、`caretakerIds=[me]`。
- 操作：建立→導向該寵物檔案。

## 附：狀態設計通則
每頁都應處理：**空狀態**（引導行動）、**載入中**、**無權限**（例如私人檔案）、**錯誤**（重試）。
目前本機原型以空狀態與停用按鈕為主；載入/錯誤在接後端時補齊。
